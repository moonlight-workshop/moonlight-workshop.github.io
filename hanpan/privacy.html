한판 개인정보처리방침

시행일: 2026년 10월 7일 · 이전 방침 시행일: 2026년 10월 3일 · 적용 앱: 한판 (com.hanpan.bakescale)

한판은 성인 홈베이커를 위한 배합 계산·레시피·굽기 기록 앱입니다. 계정, 개발자 서버, 광고, 분석 SDK 없이 작동합니다. 앱은 사용자의 개인정보를 개발자에게 자동 수집·전송하지 않습니다. 사용자가 직접 보낸 지원 문의의 처리 방식은 아래에 설명합니다.

기기에 저장하는 정보

입력한 레시피 이름·재료·무게·밀가루 지정·메모·즐겨찾기·태그·만드는 법, 보유 틀·레시피 기준 틀, 굽기 기록·날짜·배율·작성 당시 원본 배합, 마지막 선택한 배합, 계량 체크·단계·표시 단위, 마지막 성공한 파일 백업 일자와 객관적인 리뷰 요청 제한을 위한 최초 사용 시점·완료 횟수·요청 시점을 앱 전용 공간에 저장합니다. 기능 제공과 사용자 입력의 보존에만 사용합니다. 위치·연락처·광고 ID·결제 카드 정보를 읽지 않습니다.

보관과 삭제

데이터는 사용자가 삭제할 때까지 기기에 보관합니다. 레시피를 삭제해도 굽기 기록 안의 원본 배합·메모·태그·만드는 법은 남으며, 해당 굽기 기록을 삭제하면 그 안의 원본도 함께 지워집니다. 설정의 '모든 기록 삭제'를 확인하면 기록이 삭제되고 수치 연습용 예제로 돌아갑니다. 앱 삭제나 Android 설정의 앱 저장공간 삭제로도 지울 수 있습니다. 계정을 만들지 않으므로 계정 삭제 절차는 없습니다.

Android 자동 클라우드 백업은 제외합니다. Android 12 이상 지원 기기에서 사용자가 새 기기 설정의 직접 기기 이전을 선택하면 레시피와 계량 진행을 저장하는 DataStore 파일 두 개를 이전 대상에 포함합니다. 기기별 지원과 동작은 다를 수 있으며 이전 성공을 보장하지 않습니다. Android 8–11의 자동 백업은 제외합니다. 기기 분실·삭제·교체에 대비해 아래 파일 백업도 안전하게 보관해 주세요.

백업 파일과 사용자가 선택하는 공유

레시피 텍스트 가져오기는 사용자가 붙여넣기 버튼을 누를 때만 클립보드의 텍스트 한 항목을 읽습니다. 앱 시작이나 화면을 열 때 자동으로 읽지 않으며 파일·사진·주소의 내용을 불러오지 않습니다. 원문은 검토 초안으로 사용하고 사용자가 확인해 저장한 재료·수량·메모만 개인 레시피로 기기에 보관합니다.

백업 저장·복원은 Android 파일 선택기에서 사용자가 지정한 파일에만 접근합니다. 파일에는 레시피와 개인 메모가 포함됩니다. 백업은 암호화되지 않은 UTF-8 JSON이며 안전한 위치에 보관해야 합니다. 클라우드 파일 제공자를 직접 선택한 경우 해당 제공자의 정책과 보관 방식이 적용됩니다. 앱에서 기록을 삭제해도 별도로 저장한 백업 파일은 남으므로 직접 삭제해 주세요.

텍스트 공유에는 계산 결과와 레시피 메모가 포함됩니다. 이미지 공유는 현재 계산값·표시 단위의 PNG 카드를 기기에서 만들며 메모는 기본 제외하고 사용자가 선택할 때만 포함합니다. 미리보기를 확인하고 Android 공유 창에서 고른 앱으로 전달하며 자동 공유는 없습니다. 대상 앱의 정책이 적용되므로 공유 전 내용을 확인해 주세요.

생성한 이미지는 앱 전용 cache/share에 임시 보관합니다. 다음 이미지 준비 때 7일이 지난 생성 파일을 정리하며 Android도 캐시를 지울 수 있습니다. 모든 기록 삭제 때 생성 이미지 캐시도 지웁니다. 이미 다른 앱이나 외부 파일에 보관한 복사본은 별도로 지워야 합니다. 외부 앱에는 선택한 이미지의 임시 읽기 URI만 제공하며 사진·저장소·미디어·네트워크 권한을 사용하지 않습니다.

Google Play 구매와 선택적 리뷰

다운로드 시 일회 구매·환불·선택적 리뷰는 Google Play의 자체 과정에서 처리됩니다. 한판은 카드나 결제 정보 및 사용자가 리뷰 창에 입력한 내용을 앱에서 읽지 않습니다. 리뷰 API는 충분한 사용 후에만 요청하며 리뷰를 작성하지 않아도 모든 기능을 사용할 수 있습니다. 리뷰는 Google Play에 공개되거나 비공개 테스트에서 개발자에게 비공개로 제공될 수 있으며 사용자는 Google Play 또는 Google 계정에서 삭제할 수 있습니다. Google 개인정보처리방침을 참고해 주세요.
